# 数据流（DataFlow）节点配置规格

> 依据 DATAFLOW_DESIGN.md v0.3、日期 2026-10-27、本文为设计文档配套（冲突时以设计文档为准）。
> 本文把设计文档第 4 节的首版 20 个节点逐个展开为配置表单规格，并引用第 5 节（公式函数）、第 6 节（参数与字段引用校验）、第 7 节（运行体系）、第 8 节（结果查看）、第 9 节（数据规则）、第 10 节（格式边界）的既有约定，不新增设计文档之外的行为。
> 文中「待确认」指设计文档标注为建议细节、待确认或待验证的默认值；本文无法从设计文档确定的规格缺口，集中列在文末「待补充决策」，不在本文内擅自拍板。
> 术语：字段＝列，记录＝行，Sheet＝Excel 工作表；上游＝连线流入的一方，下游＝连线流出的一方。面向审计业务人员，不含技术实现细节。

## 0. 通用约定（适用于全部节点）

**画布与节点**

- 节点显示图标＋「中文＋英文」名称，按类别（输入 / 整理 / 筛选排序 / 关联合并 / 汇总变形 / 校验 / 输出）着色；运行状态着色：灰＝未运行，绿＝成功，黄＝成功但有警告，红＝失败；节点角标显示行数与耗时。
- 锚点方向：输入口在节点左侧，输出口在右侧，多路输出垂直排列。
- 凡有分支语义的节点（筛选、去重、关联、检查），多路输出必须保留，让用户继续处理「另一半」数据。
- 浏览 Browse 不设独立节点，不计入节点总数；任意节点点击即可在结果区查看。
- 输出类节点为末端节点，无输出口，但点击仍可在结果区预览结果。

**控件类型词汇表**（各节点规格表统一使用）

| 控件 | 说明 |
| --- | --- |
| 下拉 | 从候选清单中选一项 |
| 单选 | 在互斥的几个方式中选一项 |
| 文本框 | 手工输入文字 |
| 数字 | 输入数值，可带范围限制 |
| 勾选 | 在多选清单中打勾 |
| 开关 | 两态切换（开 / 关） |
| 路径选择器 | 弹出文件或文件夹选择窗口，选中才授权 |
| 字段映射表格 | 以表格方式逐字段（或逐列）配置 |
| 条件构造器 | 「字段＋运算符＋值」的条件行编辑，支持且／或组合，不必写表达式 |

**类型系统**（六类，全工具统一）：文本、整数、十进制小数、布尔值、日期、日期时间。金额等要求精确计算的字段用十进制小数；读入不统一截为两位；单价、数量、利率、汇率保留所需小数位。

**列类型建议与锁定（输入节点通用交互方式）**

1. 文件选定后，配置区显示「列类型」清单：每列一行，含列名、建议类型、当前类型。
2. 建议类型的产生：按采样给出建议（建议取前 1,000 条记录，默认值待确认）；全空或证据不足的列给出保守的文本建议并提示。
3. 每列类型可从「自动」改为六类之一；一经选定即**锁定**该列，不再自动判定（如账号列锁定为文本）。编号、账号、身份证、合同号、带前导零的代码优先建议文本；大额金额仍可为数值；不按「超过 12 位」统一转文本。自动建议仅为建议，用户可锁定覆盖。
4. 可选「全量扫描判定」（慢但准）。
5. 全量运行时逐行校验类型；不吻合的行按行级异常策略处理（默认停止并报告），不在处理途中静默换类型。

**结果区通用内容**（每个节点均有，下文各节点只列专属内容）

- 概览：状态、进出行数、字段数与类型、耗时、警告与错误清单（可导出）。
- 数据浏览：分页（建议 100/500 每页，待确认）、列筛选、搜索、点列头排序；查看方式不改变节点输出与下游数据。
- 统计按需计算：数值列（合计／平均／最小／最大）、文本列（唯一值个数）点按钮才算，算完缓存。
- 结果标明预览样本／全量、运行版本、有效／历史（失效）状态。

**预览运行通用行为**：每个输入节点各取前 N 条（建议默认 1,000，可调，默认值与调整入口待确认）；界面顶部常驻「预览模式·样本数据」横幅；关联、去重、汇总结果标注「基于样本」；预览运行不写输出文件，输出节点只在结果区展示。

**异常策略通用**

- 行级错误（可定位到具体记录，如数字／日期转换失败、除零）：可配置①停止（默认）或②跳过整行并记录；异常清单含节点、字段、原值、原因、来源与数量，并在运行摘要披露；带跳过记录的成功运行标为有警告。
- 结构性／任务级错误（缺字段、未知格式、文件损坏、资源不足、输出写入失败等）：必须停止，不能套用跳过策略。

**字段引用校验（全部节点联动）**：打开、保存、运行时统一校验——下游引用的字段在输入字段集中不存在时，集中提示「哪个节点引用了哪个字段、现在输入里没有」，首版定位到清单为止。

## 一、输入类（5 个）

### 1. Excel 输入 Excel Input

**用途**：读取 Excel 工作簿文件（xlsx / xlsm / xls / xlsb / ods，含伪装成 .xls 的文本或 XML 文件按内容识别），作为流程的数据入口。

| 方向 | 锚点 | 语义 |
| --- | --- | --- |
| 输出 | 输出 ×1 | 本节点读到的全部记录；批量模式下可附加来源列 |

**配置表单**

| 界面文案 | 控件 | 候选选项与默认值 | 校验规则与联动 |
| --- | --- | --- | --- |
| 读取方式 | 单选 | 单文件 / 文件夹批量（默认值待确认） | 选「文件夹批量」后展开批量设置组 |
| 文件 / 文件夹 | 路径选择器 | — | 必填；选中才授权；路径支持引用运行参数（如期间），运行前经参数确认页确认 |
| Sheet | 下拉（列出所选文件全部 Sheet） | 默认值待确认 | 批量模式下的 Sheet 选择规则设计文档未定义，见「待补充决策」 |
| 表头行 | 数字 | 默认值待确认 | 须为正数 |
| 数据起始行 | 数字 | 默认值待确认 | 须位于表头行之后 |
| 列类型 | 字段映射表格（列名＋建议类型＋类型下拉） | 自动（默认建议）/ 文本 / 整数 / 十进制小数 / 布尔值 / 日期 / 日期时间 | 按通用约定「列类型建议与锁定」；Excel 的数字单元格、显示格式补零与实际文本需区分（界面提示） |
| 批量：来源列显示 | 开关 | 批量读取建议默认显示（待确认） | 显示来源文件、Sheet、原始行号三列；隐藏仅是不显示，内部来源标识仍保留 |
| 批量：字段对齐方式 | 下拉 | 按字段名对齐 / 按位置对齐（默认值待确认） | 各文件列名或列数不一致时按此对齐 |
| 批量：差异报告 | 勾选（默认值待确认） | 自动生成 | 文件之间的字段差异（多出、缺失、类型不同）逐项列出；输入侧差异报告的具体内容见「待补充决策」 |
| 批量：文件清单对比 | 结果区自动展示 | — | 重跑时报告「本次读到几个文件、比上次多了哪些、少了哪些」（建议能力，交付批次待确认） |

说明：xlsb / ods 走底层已有识别路径，开放以逐项验证为准（第 10 节）；真正的老式二进制 xls 在文件过大时自动借助本机 Excel 生成 XLSX 缓存副本（源文件不替换），缺少 Excel 或转存失败才提示人工另存。

**结果区专属内容**：文件清单（批量模式含各文件行数）；单文件模式显示行数、字段数；类型建议与锁定情况；批量差异报告与文件清单对比；老式 xls 自动转存的过程消息（如发生）。

**异常策略**：结构性（必停）——文件损坏、未知格式、加密或无法读取、Sheet 不存在、缺少 Excel 且老式 xls 需转存或转存失败（提示人工另存）；行级（停止／跳过可配）——全量运行时列类型不吻合的行（默认停止并报告）。

**用途**：对字段做保留／删除、重命名、调整顺序、修改类型。

**锚点**

| 方向 | 锚点 | 语义 |
| --- | --- | --- |
| 输入 | 输入 ×1 | 上游全部记录 |
| 输出 | 输出 ×1 | 按清单处理后的记录 |

**配置表单**

| 界面文案 | 控件 | 候选选项与默认值 | 校验规则与联动 |
| --- | --- | --- | --- |
| 字段清单 | 字段映射表格（勾选保留、拖拽排序、重命名输入框、类型下拉） | 默认全部保留（待确认） | 至少保留 1 个字段；清单引用的字段在上游不存在时触发字段引用校验集中提示 |
| 改类型 | 每列类型下拉 | 保持（默认）/ 文本 / 整数 / 十进制小数 / 布尔值 / 日期 / 日期时间 | 产生精度损失的转换须显式确认（界面提示）；源中已丢失的位数不能恢复，按文本输出也不能修复 |
| 新增字段自动传递 | 开关 | 默认值待确认（见「待补充决策」） | 开＝上游新增字段自动带入下游；关＝仅传递清单内字段 |

**结果区专属内容**：进出行数相同；字段数增减、重命名与改类型清单；改类型的转换异常定位（节点、字段、原值、原因、来源标识）。

**异常策略**：结构性（必停）——清单引用字段缺失（字段引用校验）；行级（停止／跳过可配）——改类型时转换失败（如数值溢出、日期无法识别），例：「文本转整数」遇到「12A3」默认停止，可改为跳过整行并记录。

| 面板组成 | 要求 |

### 13. 关联 Join

**用途**：两张表按一个或多个字段配对关联，固定输出匹配、左未匹配、右未匹配三路；不提供改变 J 含义的内／左／右／全关联开关。

**配置表单**

| 界面文案 | 控件 | 候选选项与默认值 | 校验规则与联动 |
| --- | --- | --- | --- |

**异常策略**：结构性（必停）——关联字段类型不一致须先修正、同名字段配置后仍重名、字段缺失、多对多膨胀明显超出资源预算时明确停止并给出处理建议；无行级错误——空值键不匹配是正常语义。

## 七、待补充决策

以下事项在设计文档中无明确答案或存在缺口，本文未擅自确定，需在开发排期前逐条确认：

1. **批量读取默认值**（Excel / CSV 文件夹模式）：字段对齐方式的默认值（按字段名／按位置）未给出（设计文档仅对纵向合并节点写明默认按字段名）；批量差异报告的具体内容与是否提供处理选项未细化；来源列在单文件模式下是否提供未写明。
2. **Excel 批量模式的 Sheet 选择规则**：各文件按名称匹配、按序号取第 N 个 Sheet 还是其他方式，未定义。
3. **条件构造器运算符清单**（筛选／检查共用）：设计文档明确比较类六种与空值判断，文本包含类等其他运算符是否进入构造器待定。
4. **排序**：空值位置的候选选项与默认值；是否允许逐排序字段分别设置空值位置；相同排序键的稳定次序具体规则（设计要求「明确」，未写具体规则）。
5. **去重**：保留规则的默认值（首次出现／最后一次）未定。
6. **关联**：左右同名字段的默认命名规则具体格式未写（设计仅要求「确定的命名规则」并允许配置保留与重命名）。
7. **纵向合并**：字段差异「处理方式」的候选选项清单未列出（如多出字段保留／丢弃、类型不同如何统一）；差异未逐项处理时是否阻止运行；多表拼接次序如何确定。
8. **透视**：聚合方式是否与汇总同一清单；动态生成列的命名规则；缺失组合填充值默认（空值／0）；列字段是否支持多个。
9. **宽转长**：记录原列名的列与记录取值的列的默认字段名未定。
10. **检查节点**：关键字段非空对空文本／仅空格文本的判定口径；编号唯一是否支持分组内唯一、空值是否参与唯一性、重复记录的分流范围（仅重复者还是整组）；数值区间的边界开闭与空值处理；自定义行级条件中空值记录的通过口径。
11. **输出节点**：Excel 输出的 Sheet 名称默认值、行数超量时分片方式默认（分 Sheet／分文件）、分片文件的命名规则；CSV 输出是否支持多条上游连线（如每条连线一个文件）及其编码、分隔符、分片行数的默认值。
12. **列类型锁定适用范围**：是否适用于 .db 与 Parquet 输入（第 9 节的锁定表述主要面向类型判定场景，.db / Parquet 按源结构保留类型）。

14. **分列**：按分隔符拆分时段数不足／超出时如何补空、拆出列数上限；固定宽度切分的具体交互方式。
15. **汇总**：分组字段是否允许为空（全表作为一组）；聚合输出字段的默认命名。
16. **若干开关与默认值**：字段选择「输入新增字段是否自动传递到下游」的默认方向；首行为表头的默认勾选状态（CSV／手工输入）；手工输入各列字段类型的默认值；公式 J 路输出字段的默认勾选范围；文件读取方式（单文件／文件夹）的默认项。

## 八、待补充决策的默认裁定（2026-10-27，均可调整）

对应第七节 1–17 条，按审计使用惯例裁定如下；如与业务实际不符，改本文并同步设计文档即可：

1. 批量读取：对齐方式默认**按字段名**（以第一个文件为基准）；差异报告逐文件列出多出/缺失/类型不同三类字段；来源列在单文件模式下同样提供，默认开。
2. Excel 批量 Sheet：默认**自动取每个文件第一个有数据的 Sheet**；可切换按名称匹配，匹配不到的文件进差异报告，不静默跳过。
3. 条件构造器运算符：比较六种＋为空/不为空＋文本包含/不包含/开头是/结尾是；正则不进首版。
4. 排序：空值默认**排最后**（逐字段可改排最前）；相同排序键按输入到达顺序保持相对次序（稳定排序）。
5. 去重：默认保留**首次出现**。
6. 关联同名字段：左侧保留原名，右侧同名加后缀 **_右**（可配置改为两侧加 _左/_右）。
7. 纵向合并：多出字段默认**保留**（字段取并集，缺失侧补空值）；类型冲突默认统一为文本并提示；拼接次序按连线的添加顺序，可在配置中调整；差异未逐项处理不阻止运行，但差异报告必须完整显示。
8. 透视：聚合方式与汇总同一清单；动态列名＝列字段原值；缺失组合默认填 **0**（可改空值）；列字段首版只支持 1 个。
9. 宽转长：原列名列默认名 **项目**，取值列默认名 **数值**（均可改）。
10. 检查节点：非空判定从严——空值与纯空格文本都算空；编号唯一默认全表范围（可设分组内唯一）；空值不参与唯一性；重复记录**整组**进未通过路；数值区间按闭区间（≥下限且≤上限），空值遇区间规则判未通过并标注「空值」；自定义行级条件中空值一律按未通过处理（与筛选"空值进 F 路"口径一致）。
11. 输出节点：Excel 输出的 Sheet 名默认＝上游节点名；超 104 万行默认自动分 Sheet，分片名「Sheet名_2」递增；CSV 输出支持多条上游连线，每条连线一个文件，文件重名时自动加序号；CSV 默认编码 **GBK**、分隔符逗号、不分文件。
12. 列类型锁定：仅适用于读取时需要判类型的输入（Excel、CSV/文本）；.db 与 Parquet 按源结构保留类型，不提供锁定，仅提供类型查看。
13. 预览截样行数：在**全局设置**中统一调整（默认 1,000），不逐输入节点设置。
14. 分列：拆出的段数不足补空值；超出部分**并入最后一段**（不丢内容）；拆出列数上限 20；固定宽度模式逐段设宽度并即时预览。
15. 汇总：分组字段允许为空（全表作为一组，分组列输出空值）；聚合输出字段默认命名＝「字段_聚合方式」（如 借方金额_求和）。
16. 各开关默认：字段选择"新增字段自动传递"默认开；首行为表头默认勾选；手工输入列类型默认自动识别（超 15 位整数保底文本）；关联 J 路默认保留左右全部字段（同名按第 6 条规则）；输入读取方式默认单文件（可切文件夹）。
17. 输入/输出类节点英文名：按本文暂拟执行，实现时随界面文案统一复核一次。
