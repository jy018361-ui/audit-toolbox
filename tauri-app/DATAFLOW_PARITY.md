> 本工具为全新工具，无旧 Python 金标；本文是「设计文档条目 → 实现行为 → 验证方式」的验收矩阵，与 `DATAFLOW_DESIGN.md`（需求唯一来源）、`DATAFLOW_NODE_SPECS.md`（节点配置规格）、`DATAFLOW_ACCEPTANCE_FLOWS.md`（三条验收流程与规模场景）配套。

## 运行命令

```bash
cargo test --manifest-path src-tauri/Cargo.toml --lib dataflow:: -- --test-threads=1   # 引擎全部测试
cargo test --manifest-path src-tauri/Cargo.toml --lib bundled_catalog                  # 工具清单登记
npx vitest run src/dataflow                                                            # 前端工作流模型与页面
npm run build                                                                          # 前端类型检查与构建
python scripts/gen_dataflow_fixtures.py                                                # 重建合成测试数据（固定随机种子）
```

合成测试数据在 `tests/fixtures/DataFlow/`（用途逐文件见其 README：编码/分隔符矩阵、千分位、全角、前导零、18 位流水号、重复凭证号、伪 xls、关联用重复键映射表等）。

真实工作簿只读选表探针：设置 `DATAFLOW_INPUT_PROBE_PATH`（文件路径）与可选 `DATAFLOW_INPUT_PROBE_HEADER`（表头行，默认 1），运行 `cargo test --manifest-path src-tauri/Cargo.toml --lib real_workbook_visible_sheet_probe -- --ignored --nocapture`。输出可见表、实际选表、表头行、样本行数和字段名，不输出原始数据或改写源文件。

## 契约备忘（前后端对接细节）

- 请求体＝工作流 JSON 本体＋可选 `paramOverrides`（引擎按方法名区分预览/全量；`runMode` 字段冗余可传）；节点类型双别名（`select`/`select_n`、`filter`/`filter_n`）。
- 响应锚点 key：单输出节点为 `output`、筛选 `T`/`F`、输出节点 `sheet:名`/`file:名`。2026-10-30 修复：请求侧连线锚点字段（fromAnchor/toAnchor，驼峰）曾被引擎 serde 漏配 rename 静默当未填、一律回落 `output`——从筛选 T/F、关联 J/L/R、去重 U/D、检查 P/NG 等多出口拉出的连线在 JSON 边界上从未通过（必报「锚点 output 不存在」），单输出口连线碰巧不受影响；现有 join 用例靠边序补位与默认值巧合通过，故长期无测试暴露。修复后驼峰为契约、下划线为兼容别名，并补筛选 T→输出 的 JSON 级回归；样例每锚点 ≤200 行；十进制序列化为字符串、空值 null。2026-10-28 修复：前端规格/演示数据曾写 `out`，与引擎 `output` 不一致——真实引擎运行时结果区显示「样本数据为空」且连线锚点对不上；已统一为 `output`（nodeSpecs SINGLE_OUT、demoData、Canvas 兜底、测试夹具），并用真实引擎返回形态在浏览器端到端验证表格/行数/状态显示。
- 单节点行数上限默认 100 万行（`MAX_TABLE_ROWS`），超限中文报错不静默截断；2026-11-07 起请求可带 rowLimit（1000–5000 万；不传＝引擎按本机可用内存自动推导，每行约 2KB 预算、夹 100 万–5000 万——用户无需手动设置；工具栏下拉默认「自动」，手动档保留），引擎读取预算与全部膨胀预检统一用该值；再大规模待三期流式落盘。三期流式改造（2026-10-30 完成）：引擎内部表传递改为共享同一份（Arc 指针），全量运行中同一张表不再同时存在约 4 份深克隆——终态锚点只保留前 200 行样本、行数仍报全量（哨兵测试锁定），输入读取逐文件转换完即释放原始数据，清洗/排序改为需要改写时才复制；行级克隆（筛选/去重/检查的按行分区、公式行副本）属语义性成本保留，未做行句柄化。JSON 契约逐字不变（前端 124 项测试原样通过），引擎 82 项测试含 ptr_eq 共享性哨兵。
- 全量运行目前走同步 engine_call（长任务 job 化、增量重跑属第三期）。
