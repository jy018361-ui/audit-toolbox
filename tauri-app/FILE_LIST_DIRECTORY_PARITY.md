## 2026-08-05 迁移差异审计与修复

本轮对九个工具做了逐项"旧版 vs 新版"审计，结论按"功能没了 / 结果可能不一样 / 少了提醒 / 本来就该丢掉 / 新版更好 / 光看代码说不准"六类归档。
以下只记录**本工具**已落地的修复；**尚未用真实脱敏底稿验证**，所有"已修复"仅代表通过了合成回归。

### 已修复

- **无权限子目录导致整单失败**：原实现遍历时遇到读不动的目录即中止，**一个文件都不导出**；共享盘上只要有一个他人私有目录，工具即完全不可用。现改为跳过并回报被跳过的路径清单（扫描预览与导出结果都会列出），既不漏数也不阻断。
- **扫描阶段无进度、无法取消**：`file_list.scan` 改走任务通道，遍历过程中定期检查取消，误选 `C:\` 或共享盘根目录不再只能强杀程序。
- **输出文件被静默覆盖**：输出路径是自动填好的，因此旧版"另存为"对话框连带的 Windows 覆盖确认从不出现；若用户曾在上一份清单上加过复核批注，重跑即无声丢失。现增加确认。
- **扫描到的跳过路径不显示**、**导出耗时无预期文案**，均已补。

### 与旧版的已知差异（保留新版行为）

- **文件顺序不同**：旧版逐层列完本层文件再进子目录，新版遇子目录即深入，父层文件被劈成两段。行数与内容一致，仅行序不同——**跨年度并排比对两份清单前需先按"文件路径"列排序**。
- **路径斜杠已规范化**（旧版会出现 `C:/客户资料\合同\A.pdf` 这种混用），与 1.x 导出的清单做文本比对时需先统一。

### 仍需真机验证

- 映射网络盘（`Z:\`）上的超链接与路径列是否会被规范化成 UNC 形式——两种都能点开，但按盘符做文本匹配的索引表会对不上。
- 超过 260 字符的深层路径、`subst` 虚拟盘、OneDrive 按需下载占位文件的表现。
