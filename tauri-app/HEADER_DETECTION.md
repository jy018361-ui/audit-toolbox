# 表头结构公共判据

## 2026-10-21：结构候选优先、表头边界及非数据页

- 公共候选筛选先检查短字段锚点、段落比例及正文取值，随后才由各工具自己的字段词表排序。说明段落不能仅因包含期初、科目、余额等词冒充表头；候选需要后续多行列位证据，只有表头而无正文时仍可读取，但合并界面提示复核。纯文本正文不强制有金额／日期。
- 普通 TB／JE 与稀疏 OOXML 预览共用 `infer_numbered_header_layout`，物理行号独立保留，只有实际相邻的行可联合成双层。公共分组下层判据新增“同名身份字段＋重复下层标签”的结构佐证，覆盖自有 FA 汇总导出的第1～2行；第3行开始保留正文。
- 键值位置稳定、键为短文字、首项及多项值有实际参数取值证据时标为 `key_value`；证据不足的两列纯文本清单仍保留为数据表候选。空表与前缀未见数据的未定页区分。通用识别仍有采样窗口，不声称可自动推断任意版式。
- 合并预览参数页不推断业务字段，以零层表头从首行原样保留；空表明确标注并无正文输出。两种导出均保留零层语义，原样页出现预览之外的新列时停止，不能静默丢列。未明确选择基准时跳过空表／参数页，明确指定非数据页则报告原因。
- 其他自动业务读取入口对明确参数页返回 `SOURCE_NOT_TABULAR`，用户明确指定表头可覆盖；批量 TB／JE 上传仅逐 Sheet 忽略该明确错误，不撤销同本有效账表，整本无可读数据及其他失败仍报告。
- 适用入口：TBJE、汇兑、存款、借款 TB／JE；固定资产清单与子工具；借款／利率台账；模糊匹配普通／磁盘；TS／看账自动行号解析。业务词表、金额与结构计算公式不改。固定模板的指定列读取未改成自动推断。
- 公共表缓存、自动行号／选表记事、FA 整表／前缀／结果及五个账表工具结果缓存引用表头规则版本，旧识别结果不复用。
- 回归：`cargo test --manifest-path src-tauri/Cargo.toml --lib header_structure -- --include-ignored`；三份原件用 `HEADER_STRUCTURE_NATIVE_ROOT` 指向原始目录（含用户三个文件），可用 `HEADER_STRUCTURE_REPORT` 保存元数据和导出校验统计。另跑 `--lib fx::`、`--lib 通用表头`、`--lib excel_`、各消费者定向回归及前端 `src/ledgerWorkbookSheets.test.ts`。

## 2026-10-21 跨工具空表头、首条正文与物理坐标排查

- 借款／利率台账普通 Excel 读取复用公共物理行列恢复函数，与轻量／磁盘读取确认相同坐标，避免顶部空行、左侧空列被裁剪后再按已确认行号重读错行。
- 通用双层判据增加正文取值保护：下层出现实际金额或日期时不能因名称／备注命中关键词就吞作表头；上层多个实际数值同样阻断。纯年份分组保留例外。固定资产清单、借款／利率台账、模糊匹配继续使用各自字段评分，不套用 TBJE 业务词表。
- 固定资产清单按已读取正文宽度补齐空标题尾列；磁盘任务继续补到全表实际宽度，不截掉预览窗口后才出现的列。
- 已确认表头的 Polars／CSV 路径也调用公共列名规则，避免自动识别为“列N”、正式重读却变为“Column_N”。
- 公共合并列名只对双层上层横向延续；单层空标题保持按列位置生成的占位名称，不能借用左侧字段名。作用于公共 TB／JE 与磁盘读取消费者，原有双层分组保留。
- 共享表缓存、FA 选表／前缀／匹配快照、借款结果快照纳入公共表头规则版本，旧识别结果自动失效。
- 回归：`cargo test --manifest-path src-tauri/Cargo.toml --lib 通用表头`，以及 `--lib fx::`、`--lib fa::`、`--lib fa_sheet_pick::`、`--lib fa_merge_snapshot::`、`--lib fuzzy_match::`、`--lib loan_interest::`、`--lib disk_table::`、`--lib tabular::`。覆盖首条金额／日期、物理偏移、确认重读、前缀／普通／磁盘一致及原双层正例。

## 2026-10-21 Excel 合并与 TBJE 共用行号／层数判定

- Excel 匹配预览直接调用 `fx::infer_public_header_layout`，与公共 TBJE 账表候选行、双层增量与首条正文保护保持同一实现，不再以独立的宽松下层判断或合并区域强制上移。
- Calamine 预览与正式匹配导出均恢复原始物理行列，顶部空行和左侧空列不再改变用户确认坐标。单层空标题显示按位置生成的「列N」，列匹配保留同名列独立槽位。
- 匹配页人工修改模板表头只同步模板来源 Sheet，其余输入使用各自的行号／层数，正文预览同步更新。文本型 XLS／CSV 快照按确认的表头起点复核，非首行表头不会再与文件标题行比较。
- 验证命令及六份真实特殊 TBJE 原件、五类补充样本见 `EXCEL_MERGER_PARITY.md` 同日条目。本次未修改公共 TBJE 业务字段、金额或结构规则，也未声称支持任意无表头数据的自动推断。

## 2026-09-26 接入范围

`src-tauri/src/header_detection.rs` 提供与业务词表无关的结构判断：规范化后的不同标签数量、重复标题排除、候选行排序、双层分组与正文证据。各工具继续提供自己的关键词评分；相同分数优先较早的行。只有单列的来源保留原评分兜底，不因标签数量少而拒绝读取。

| 来源 | 接入行为 |
| --- | --- |
| TB／JE 共用读取 | 双层上层不同分组数量复用公共判据；原有账表评分及大文件物理行号处理保留 |
| 固定资产主清单／补充清单 | 保留资产关键词和选 Sheet 评分；自动双层列名合并，后续按确认起始行重新读取时使用相同层数 |
| 借款／利率台账 | 保留台账关键词；`headerDepth=0` 联合探测，显式 1／2 层覆盖；两层均不进入正文 |
| 模糊匹配 | 保留名称类关键词；新文件自动识别，检测层数传给匹配任务及历史恢复 |
| Excel 智能合并 | 共用重复标题排除；保留已有合并区域、置信度和人工复核机制 |
| TS | 当前界面明确指定标题行，保留此约定；未新增自动识别入口 |

双层必须同时满足：上层有至少两个不同标签且存在分组形态；下层以文字为主、至少两个业务字段；下一行存在数值或日期数据。合并使用公共列名规则。没有足够证据时按单层读取，可手动指定已支持的层数。

限制：通用台账结构检测尚未读取 XLSX 合并区域；靠单元格形态推断。不把全为文本的正文当成双层佐证。固定资产接口尚无独立手动层数参数；可手动选下层作为单层字段行。非账表工具尚未迁入账表的大文件流式预览策略。
