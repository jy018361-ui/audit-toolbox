# 表格交互与正式读取约定

## 2026-10-26：Excel 2003 XML

SpreadsheetML 目录扫描 XML 取得 Sheet 元信息后独立缓存，不解析金额或单元格值。公共行访问器逐行保留物理位置，预览达到窗口立即停止；完整读取仍检查尾部数据。旧整表读取器使用原生、仅含值的缓存副本，模板版式保留沿用 Excel 转换。能力及回归见 `XLS_INPUT_COMPATIBILITY.md`，不将单文件 XML 目录扫描描述为 ZIP 式目录随机访问。

## 2026-10-26：完整分页预览不重复解码整表

借款大台账／利率台账的完整分页预览使用源缓存上的非空行位置索引；首次完整识别按原规则扫描一次建立精确计数和映射，后续页直接范围查询。初始轻量前缀仍不建索引。旧源缓存兼容懒建，事务失败／取消不发布半成品；空白行、行序和偏移保持，完整业务读取仍检查全部必需行。针对性回归和合成探针见 `LOAN_INTEREST_PARITY.md`。

公共完整 TB 分析的任务内复用见 `LEDGER_MAPPING_UNIFICATION.md` 同日条目；原始表缓存命中不再等于每个阶段都重新物化相同的分析库。并非所有工具的所有完整扫描都已消除。

## 读取阶段

1. 只需要 Sheet 列表时只解析目录，XLSX 不读取共享字符串或工作表正文。
2. 预览读取指定窗口后停止，不先整表物化、建立全宽 SQLite 或统计精确总行数。指定较后表头时读取覆盖该行及必要样例的窗口。
3. 单个 ID 只证明列对应的样例证据，不代表全表覆盖率或唯一性。先查已有前部样例；需要补深才定向读取，找到足够证据就停。组合键仍保留各成员。
4. 正式匹配、重复键、科目全集、精确统计和导出读取全部必需记录，不以预览截断业务结果。

## 共用缓存

- `table_read_cache.rs` 提供跨 worker 的预览、选列、样例证据及必要完整矩阵缓存。键包括规范路径、大小、纳秒修改时间、业务用途、调用参数和公共表头规则版本；表名、表头行／层数、选列或归一化设置改变不会误复用。
- 只缓存真实完成的读取，不预读来填缓存；开始／结束指纹不同或读取报错不发布缓存。唯一临时文件写完后替换，损坏时删除回源；缓存写入失败不阻断业务结果。
- JSON 以流式方式写出，避免再复制完整序列化内容。单项上限 256 MiB、本层总量 1 GiB，超量按最近使用淘汰；超过单项上限的读取正常完成但不保存本层缓存。公共缓存统计／清空／按日清理覆盖其 JSON 文件。
- 大文件的完整数据继续复用现有 SQLite／Parquet，JSON 层不替代正式磁盘读取计划。源文件发生变化、缓存被清理或写入失败时重新读取属于正常行为。

## 接入与边界

| 入口 | 调整 | 必要全量读取 |
| --- | --- | --- |
| Excel 合并 | 目录读取＋公共有界预览，模板／来源同一窗口复用 | 正式合并和表头快照核验 |
| 两列模糊匹配 | 所有上传仅前部；普通正式匹配逐行只保留所选列并缓存 | 所选列完整记录与候选匹配 |
| FA 清单／折旧／政策 | 前缀优先，不提前建完整 SQLite；键校验投影并早停，补充表同组样例验证跨 worker 复用 | 正式匹配、补充聚合、折旧与导出 |
| TS／看账 | XLSX 目录与公共轻量自动选表，缓存命中不先打开原工作簿 | 首次完整缓存、精确科目统计、筛选与透视 |
| 函证进度 | 检查真实全读后缓存，处理跨 worker 复用 | 首次银行／往来等精确统计 |
| 借款／利率普通台账 | 已读取的原始矩阵跨识别、表头修改和计算复用 | 完整贷款卡片和正式计算 |

XLSX 的共享字符串可能需要完整建立公共文本字典，这是解析前部单元格的格式依赖；只列目录不会触发它。旧式 XLS／ODS 的兼容库可能必须整本解析，不能承诺这些格式有 XLSX 相同的早停能力，但其可缓存预览会复用。正式业务的公式、金额、行序、人工映射和输出范围保持；TS 自动选表改用声明规模，其与旧实际有数行评分的差异见 `TS_PARITY.md`。
