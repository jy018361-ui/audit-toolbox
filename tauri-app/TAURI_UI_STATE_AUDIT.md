# Tauri 界面状态审查基线

这份清单约束当前 18 个 React 工具页的 UI 审查范围。界面验收不能只看初始静态页，必须以
“页面 × 状态 × 视口”作为最小审查单元；任务事件新增或改变可见状态时，同一轮必须补对应状态检查。

现有 `TaskStateFixture` 只验证共用进度、错误和结果组件能承受长文案；它不能替代真实工具页检查。
状态组件插入页头、步骤条、卡片或表格后的相邻间距与滚动归属，必须在对应页面单独验收。

## 状态矩阵

每个适用页面至少覆盖以下状态：

| 状态 | 必查内容 |
| --- | --- |
| 初始/空数据 | 主操作是否靠近输入；空状态不靠固定高度制造大块空白 |
| 文件已选/识别中 | 进度或忙碌提示出现后，原有控件不跳位、不重复占位 |
| 识别完成/有数据 | 文件名可截断；预览区与页面背景有明确边界；必填映射状态可见 |
| 展开详情/映射 | 展开内容与触发项同宽；不得用固定左缩进制造空洞；只保留一层滚动容器 |
| 任务运行/取消 | 进度条出现和消失不改变无关区块间距；主按钮位置稳定 |
| 成功/失败/部分成功 | 结果或错误插入后不挤压关键操作；长文案换行且不撑破网格 |
| 空结果/超长数据 | 空表有明确说明；宽表横向滚动归表格自身；长列表不拖垮页面 |

## 视口矩阵

- Windows 100%：1920 × 1080、1440 × 900。
- Windows 125%：1536 × 864 等效视口。
- Windows 150%：1280 × 720 等效视口。
- 每个视口同时检查页面纵向滚动、表格横向滚动和键盘焦点是否被粘性区域遮挡。

## 布局验收规则

1. 间距只使用现有 4/8/12/16/24/32/48 px token；相邻容器的外边距不能叠加成无意的大空档。
2. 同一操作组共用一条对齐线；按钮因文字过长需要换行时，先精简可见标签并保留准确的无障碍名称。
3. 展开态跟随所属行或卡片的可用宽度，不使用“为对齐某列”写死的左侧空白。
4. 一个视觉区块只设一个滚动归属：页面、详情面板、数据表不能同时套同方向滚动。
5. `min-height` 只用于稳定明确的预览/拖放目标；不能为了“撑满”空状态或任务状态而使用。
6. 文件路径只用于 `title` 或诊断信息；可见文本统一显示文件名并支持省略。
7. 原生 `select` 显式设置背景与文字色；已映射、已适配、未适配必须同时由文字和颜色区分。

## 18 个工具逐项覆盖

下表不是按页面族抽样；每个 catalog 工具均单独登记其会改变布局的状态和本轮检查结论。

| 工具 ID | 工具 | 必查事件状态 | 本轮结构审查 |
| --- | --- | --- | --- |
| `fx_audit` | 汇兑损益测算 | JE/TB 识别、映射展开、LLM 复核、测算/勾稽 | 共用页根接管状态间距；预览边界、映射完成色和文件名显示纳入回归 |
| `deposit_interest` | 存款利息收入测算 | JE/TB 识别、映射、利率设置、计算/导出 | 与汇兑页共用状态节奏；输出位置只显示文件名 |
| `loan_interest` | 借款利息测算 | 台账或 TB+JE 切换、映射、利率、重算 | 与汇兑页共用状态节奏；输出位置只显示文件名 |
| `fa_list` | FA List 匹配工具 | 双表/补充表导入、字段映射、匹配、导出 | `fa-stack` 与页根不再叠加外边距，宽表滚动留在预览区 |
| `fa_dep_calc` | 折旧测算 | 文件导入、字段识别、科目复核、导出 | 已消除步骤条后 44px 空档并收紧导入卡内部节奏 |
| `fa_policy_compare` | 折旧政策对比 | 两期文件、字段映射、政策复核、导出 | `fa-stack` 状态插入间距归零，文件输入沿用共用文件名组件 |
| `kanzhang` | 看账工具 | 导入、映射、批次/科目筛选、透视、导出 | 页根统一 16px 网格；移除浮动的磁盘分批实现说明 |
| `je_sign_mark` | 正负数凭证标记 | 导入、映射、筛选、任务进度、结果 | 与看账页共用页根网格；输出位置只显示文件名 |
| `ts_manager` | TS 管理 | 文件导入、扫描、筛选/透视、导出 | 页根接管步骤、错误和进度间距；输入输出使用共用文件名组件 |
| `confirmation_progress` | 函证进度小能手 | 导入、识别、处理、失败、输出 | 页根/卡片首个状态组件外边距归零；输出按钮只显示文件名 |
| `Excel_Merger` | Excel 批量合并 | 空队列、队列变化、扫描、合并、部分失败 | 去除 560px 固定最小高度；队列回退文案不再显示完整路径 |
| `file_list_directory` | 文件夹超链接清单 | 扫描、预览、输出、覆盖确认、导出 | `fa-stack` 间距统一；输出框和覆盖提示只显示文件名 |
| `pdf_to_excel` | PDF 转 Excel | 空队列、批量队列、转换、取消、结果 | `fa-stack` 间距统一；队列项只显示文件名 |
| `audipick` | AudiPick 智能合同审阅 | 项目、文档、模板、长任务、日志 | 导航到工作区的 32px 特例收敛到 16px，事件区不另造大空档 |
| `audit_roll_forward` | WP Roll Forward | 项目/目录选择、检查、长任务、历史结果 | 路径控件统一为只读文件名显示；任务结果区保持自身滚动归属 |
| `wp_service_generator` | FY27 WP 服务单生成 | 文件校验、生成、失败、输出 | 步骤条到工作区的共享相邻间距归零；结果文件仅显示文件名 |
| `fuzzy_match` | 两列模糊匹配 | 双文件导入、匹配、人工确认、空结果 | 共用页根接管事件组件间距，文件输入和预览滚动归属一致 |
| `tbje_check` | TBJE 完整性核对 | 多配对组、映射展开、运行、勾稽、导出 | 去除 116px 固定缩进和嵌套纵向滚动；映射操作稳定为两列 |
