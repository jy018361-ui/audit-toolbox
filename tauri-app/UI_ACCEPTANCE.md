## 样式与对比度

- 清除共享 CSS 原有非 token 颜色及 `!important`；页面状态色改为语义 token。
- 设置页 reduced-motion 保留一条明确例外，不以扩大遗留基线掩盖新增问题。
- 九套主题的四类文字与四类工作背景配对达到 4.5:1；控件边界及焦点 token 达到 3:1。
- 次要按钮使用控件边界色，危险按钮使用实色边界。卡片分隔线不作为交互控件边界处理。

## 复现

1. `npm run build`
2. `npx vite preview --host 127.0.0.1 --port 1422`
3. `node scripts/ui-acceptance.cjs`
4. `npx vitest run --exclude=.claude/**`

脚本使用已安装的 Chrome 和 playwright-core，截图及 JSON 报告写入系统临时目录，并输出具体位置。有溢出、无标签控件或焦点错误时以非零状态结束。

## 验收边界

- Chromium deviceScaleFactor 是浏览器像素密度模拟，**不是改变 Windows 显示设置后的原生 Tauri/WebView2 验收**。
- 当前工具不支持操控 Windows 原生窗口；原生标题栏按钮遮挡、系统 100% / 125% / 150% 缩放切换、NVDA 读屏仍须在桌面运行环境实测。
- 浏览器不执行本机文件业务。本矩阵验证初始/空状态；已加载数据、任务结果和 Dialog 状态由组件/工作流测试覆盖，不等同于所有业务数据的截图验收，也不宣称完整 WCAG 认证。
